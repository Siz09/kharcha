# Kharcha: Future Ideas & Deferred Features

This file holds features and ideas deferred from v1 scope. The v1 scope in `docs/PRD.md` is strictly frozen.

## v1.1 Candidates
- Bikram Sambat (BS) date conversion and calendar support.
- Per-category budgets with threshold notifications.
- Recurring ledger entries.
- Dedicated `AuditLog` table tracking entity edits.
- Expanded fixture corpus built from user-corrected scans.

## v2 Candidates
- Khalti and local mobile banking receipt parsers.
- Udhar (credit/debt) ledger tracking.
- Interactive charts and expense trend visualization.
- Home screen quick-add widget and Android App Shortcuts.
- Biometric authentication lock (Fingerprint / Face Unlock).
